# 海洋消消乐 · 背单词

一个手机优先的网页三消游戏，把英语单词记忆融入海洋主题的消除玩法中。

## 项目解决什么问题

传统背单词方式枯燥、容易走神。本项目把单词记忆和三消游戏结合：玩家每消除一组棋子，就自动看到这个单词的中文释义并听到标准发音，在轻松的游戏过程中反复接触单词，降低记忆门槛。

## 主要功能

### 核心玩法
- **6×6 棋盘**：棋子是小丑鱼、蓝吊、海马、海星、章鱼、扇贝、海龟、水母 8 种海洋生物，每只棋子上标注一个英文单词
- **交换消除**：点击选中棋子，再点击相邻棋子进行交换；三个及以上相同单词连成一线即消除
- **下落补位与连锁**：消除后上方棋子自动下落，顶部补充新棋子；下落过程中产生的新连线会自动连锁消除
- **步数与目标**：每局 20 步，收集 30 个海洋光点即可通关；步数耗尽可重新挑战

### 单词学习
- **四级难度可选**：小学（800 词）、初中（200 词）、高中（195 词）、大学（200 词），每局从对应词库随机抽取 8 个单词
- **自动语音朗读**：每次消除后底部弹出单词卡片，显示英文单词 + 中文释义，自动用浏览器语音先读英文再读中文
- **朗读控制**：右上角可一键开关朗读；卡片上有「再听一遍」按钮可重新播放

### 视觉与交互
- 清新治愈深海浅滩风格：浅海蓝、奶白、淡珊瑚粉、浅青低饱和配色，背景有上浮气泡动画
- 棋子为圆润立体造型，带水光高光；消除时有气泡上浮、光点飘散特效
- 手机端首屏即见棋盘，顶部仅保留步数、光点进度和语音开关

## 安装方法

本项目是纯静态网页，无需安装任何依赖。

```bash
# 克隆或下载项目后，进入游戏目录
cd ocean-match-game
```

文件结构：

```
ocean-match-game/
├── index.html      # 游戏入口
├── style.css       # 样式
├── game.js         # 游戏逻辑
└── words-data.js   # 单词数据库（小学/初中/高中/大学）
```

## 使用方法

直接用浏览器打开 `index.html` 即可开始游戏：

1. 在开始界面选择难度（小学 / 初中 / 高中 / 大学）
2. 点击一个棋子选中（棋子放大高亮），再点击相邻的棋子进行交换
3. 三个及以上相同单词连成一横排或一竖排即可消除
4. 消除后底部弹出单词卡片，自动朗读英文和中文释义
5. 在 20 步内收集 30 个海洋光点即可通关；步数用完可点「再玩一次」重新挑战

> 提示：语音朗读依赖浏览器的 Web Speech API，首次交互后自动解锁；建议使用 Chrome / Edge 浏览器以获得最佳语音效果。

## 输入输出示例

**输入**（玩家操作）：

| 操作 | 说明 |
|---|---|
| 点击棋子 A | 选中该棋子，棋子放大并高亮边框 |
| 点击相邻棋子 B | 与 A 交换位置；若形成三连则消除，否则自动换回 |
| 点击右上角喇叭图标 | 开关自动朗读 |
| 点击卡片「再听一遍」 | 重新朗读当前单词 |

**输出**（游戏反馈）：

| 场景 | 效果 |
|---|---|
| 成功消除 | 棋子放大后消失，气泡和光点特效飘散，光点计数 +N |
| 消除完成 | 底部滑出单词卡片，显示 `ruler` / `尺子`，自动朗读英文 + 中文 |
| 达成目标 | 弹出通关面板，显示收集光点数，可重玩或返回选关 |
| 步数耗尽 | 弹出失败面板，显示已收集光点数 / 目标数，可重新挑战 |

**单词数据格式**（`words-data.js` 内嵌）：

```js
const WORD_BANKS = {
  primary: [{ en: "ruler", cn: "尺子" }, { en: "pencil", cn: "铅笔" }, ...],
  junior:  [{ en: "ability", cn: "n.能力；才能" }, ...],
  senior:  [...],
  college: [...]
};
```
